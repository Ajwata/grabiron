⚠️ ВАЖЛИВО!
Цей сайт використовує ES Modules та потребує HTTP сервера. НЕ відкривайте index.html безпосередньо у браузері (file://)!

🎯 Швидкий старт

1 Оберіть метод запуску:

Варіант A: Python (найпростіше, якщо є Python)

cd grabiron
python -m http.server 8000

Потім відкрийте: http://localhost:8000

Варіант B: Node.js

npx http-server -p 8000

Варіант C: PHP

php -S localhost:8000

Варіант D: VS Code Live Server (рекомендовано для розробки)

  1. Встановіть розширення "Live Server" в VS Code
  2. Відкрийте папку проєкту в VS Code
  3. Клацніть правою кнопкою на index.html
  4. Оберіть "Open with Live Server"
2 Відкрийте браузер та насолоджуйтесь!
Відкрити сайт (localhost:8000) Каталог продукції

📝 Редагування продукції

Всі продукти завантажуються з файлу:

data/products.json

Змініть цей файл, щоб:

  • Додати нові серії продукції
  • Оновити характеристики моделей
  • Змінити описи та переваги
  • Додати нові категорії

🎬 Відео-фон

Поточний статус: Сайт використовує SVG placeholder як фон.

Щоб додати реальне відео:

  1. Завантажте відео з безкоштовних джерел:
    • Pexels
    • Pixabay
    • Videvo
  2. Збережіть як assets/video/hero.mp4 та hero.webm
  3. Рекомендований розмір: 1920x1080, 10-30 секунд
