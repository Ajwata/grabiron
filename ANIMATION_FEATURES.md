# 🏭 Grabiron Industrial Animations - New Features

## Добавленные декоративные элементы и анимации

### 8. 🔩 Corner Bolts (Угловые болты)
**Где:** `.benefits-bar`, `.products-section`, `.industries-section`, `.cta-section`

Декоративные металлические болты в углах секций с:
- Реалистичным 3D эффектом (градиент, тени)
- Крестообразной головкой болта
- Мягкой пульсацией (разные задержки для каждого угла)
- Адаптивным размером (18px → 14px на мобильных)

**Стиль:** Индустриальный, металлический, тонкий

---

### 9. 🔧 Floating Tools (Парящие инструменты)
**Где:** `.products-section`, `.about-intro`

Три парящие иконки инструментов (гаечный ключ, шестеренка, галочка):
- Плавная анимация вверх-вниз с вращением
- Очень низкая прозрачность (8%) для тонкого эффекта
- Разные позиции и скорости анимации
- Скрываются на мобильных устройствах (<480px)

**Стиль:** Тонкий, ненавязчивый, профессиональный

---

### 10. 📊 Animated Stat Counters (Анимированные счетчики)
**Как использовать:** Добавьте атрибут `data-stat-count="число"` к элементу

```html
<div class="stat-number" data-stat-count="500">500+</div>
```

**Функции:**
- Анимация подсчета от 0 до целевого числа
- Сохранение суффиксов (+, %, и т.д.)
- Эффект свечения во время подсчета
- Срабатывает при прокрутке в зону видимости
- Запускается только один раз

**Где используется:** Секция статистики на главной странице

---

### 11. 💫 Pulse Indicators (Пульсирующие индикаторы)
**Где:** `.btn-primary`, `.cta-button`, `[data-pulse]`

Пульсирующее кольцо вокруг важных кнопок:
- Расширяющееся кольцо оранжевого цвета
- Исчезающая анимация (2 секунды)
- Ускоряется при наведении (1 секунда)
- Автоматически применяется к основным кнопкам

**Стиль:** Привлекающий внимание, но деликатный

---

### 12. ⚡ Welding Sparks (Сварочные искры)
**Где:** Границы секций `.benefits-bar`, `.products-section`, `.industries-section`

Тонкие искры сварки на верхней и нижней границе секций:
- 5 искр на линии с разными задержками
- Появляются при прокрутке секции в зону видимости
- Эффект свечения и движения вверх
- Очень тонкая прозрачность (30%)

**Стиль:** Промышленный, эффект сварочных работ

---

### 13. ⭐ Quality Badges (Значки качества)
**Где:** `.product-card[data-premium]`, `.benefit-blob-card`, `.feature-card`

Звезда качества в правом верхнем углу карточек:
- Плавающая анимация вверх-вниз
- Вращение на 360° при наведении на карточку
- Эффект свечения (drop-shadow)
- Оранжевый цвет бренда

**Стиль:** Премиум, качество, доверие

## 🎨 Принципы дизайна

Все элементы следуют философии Grabiron:

1. **Тонкость** - Низкая прозрачность (5-40%), ненавязчивость
2. **Индустриальность** - Металл, болты, сварка, инструменты
3. **Производительность** - CSS-only анимации где возможно
4. **Доступность** - Поддержка `prefers-reduced-motion`
5. **Адаптивность** - Responsive дизайн, скрывается на малых экранах

---

## 🚀 Как использовать

### Автоматически применяется:
- Болты - на основные секции
- Парящие инструменты - на секции продуктов
- Пульсация - на все `.btn-primary`
- Искры - на границы секций

### Вручную добавить:
```html
<!-- Анимированный счетчик -->
<div class="stat-number" data-stat-count="500">500+</div>

<!-- Пульсирующий элемент -->
<button data-pulse>Custom Button</button>

<!-- Премиум карточка со значком -->
<div class="product-card" data-premium>...</div>
```

## ⚡ Производительность

- **CSS-only анимации**: Используют GPU acceleration
- **IntersectionObserver**: Эффекты только при видимости
- **Lazy initialization**: Элементы создаются по требованию
- **Reduced motion**: Поддержка системных настроек
