# Инструкция: Кнопка скачивания каталога на странице товара

## Что было сделано

Добавлена кнопка скачивания PDF каталога в раздел "Specifications & Dimensions" на странице детального просмотра товара.

## Изменения в файлах

### 1. **js/i18n.js** - Переводы
Добавлены новые ключи перевода:
- `download-catalog` - "Download Full Catalog" / "Завантажити повний каталог"
- `catalog-pdf-info` - "Complete product information and specifications" / "Повна інформація про продукцію та характеристики"

### 2. **products/detail.html** - Страница товара
- Добавлена секция с кнопкой скачивания после изображений спецификаций
- Добавлены стили для красивой кнопки с анимацией и hover эффектами
- Кнопка автоматически переводится на выбранный язык

### 3. **assets/pdf/** - Папка для PDF файла
- Создан README.md с инструкцией
- Создан шаблон HTML каталога (catalog-template.html) для примера

## Как использовать

### Шаг 1: Создайте PDF каталог
Вам нужно создать PDF файл с информацией о ваших товарах. Вы можете:

1. **Использовать шаблон**: Откройте файл `assets/pdf/catalog-template.html` в браузере и сохраните его как PDF (Ctrl+P → Save as PDF)

2. **Создать свой PDF**: Создайте свой каталог с:
   - Информацией о продукции
   - Техническими характеристиками
   - Размерами и спецификациями
   - Контактной информацией

### Шаг 2: Сохраните PDF файл
Сохраните созданный PDF файл как:
```
assets/pdf/product-catalog.pdf
```

### Шаг 3: Проверьте работу
1. Откройте любую страницу товара в браузере
2. Прокрутите вниз до раздела "Specifications & Dimensions"
3. Вы увидите красивую секцию с иконкой и кнопкой скачивания
4. Нажмите на кнопку - PDF файл начнет скачиваться

## Как выглядит кнопка

Кнопка отображается после изображений спецификаций и включает:
- 📄 Иконку PDF документа
- Заголовок на выбранном языке
- Описание "Полная информация о продукции"
- Стильную оранжевую кнопку с анимацией
- Hover эффекты и плавные переходы

## Настройка

### Изменить путь к PDF файлу
Если хотите использовать другое имя файла, найдите в `products/detail.html` строку:
```html
<a href="../assets/pdf/product-catalog.pdf" download="Grabiron-Products-Catalog.pdf"
```

Измените:
- `href="../assets/pdf/product-catalog.pdf"` - путь к вашему файлу
- `download="Grabiron-Products-Catalog.pdf"` - имя файла при скачивании

### Изменить тексты
Измените переводы в файле `js/i18n.js`:
- Найдите ключи `download-catalog` и `catalog-pdf-info`
- Измените тексты на нужные вам

### Изменить стили кнопки
В файле `products/detail.html` найдите стили `.btn-pdf-download` и измените:
- Цвета (`background`, `color`)
- Размеры (`padding`, `font-size`)
- Эффекты (`box-shadow`, `transform`)

## Примечания

- ⚠️ **Важно**: PDF файл должен существовать по указанному пути, иначе будет ошибка 404
- ✅ Кнопка автоматически переводится на английский и украинский
- ✅ Адаптивный дизайн - работает на всех устройствах
- ✅ Красивые анимации и hover эффекты

## Пример HTML шаблона

В папке `assets/pdf/catalog-template.html` есть готовый шаблон каталога, который вы можете:
1. Открыть в браузере
2. Отредактировать под свои нужды (добавить свои товары)
3. Сохранить как PDF (File → Print → Save as PDF)
4. Переименовать в `product-catalog.pdf`
